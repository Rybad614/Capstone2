## Site Tour:

On the landing page, a user will be prompted to log in or sign up. They also can view our `Privacy Policy` and `Terms of Service` if they choose (DOES NOT exist yet).

After logim/registration the user will then be directed to the home page. This page consist of a large calendar for viewing and managing events, the list of team members associated with a user, the ability to view profile pages of logged in user and its associated members, and a groupchat tab for messaging.
`LRG Scale Calendar`: Operations are all done on the home page. By clicking on a selected date, events held on that day will be displayed. A user has the ability to add an event to that date by clicking `ADD EVENT`, which will then bring forth an event form.
`Team Members` Tab: Located to the left of the screen, gives you a list of associated members and the ability to add to that list. By clicking on a member, the user will be directed to the profile page of the selected member. By clicking on the add members button, the user is directed to the add member form.
`GroupChats` Tab: A user can be apart of multiple groupchats. this allows the flexibilty for direct messaging and exclusion of certain members if needed. By clicking on a chat, the user will be directed to the chatroom where live messaging is held.
`Logout ...`: By clicking, the user is successfully signed off the app and directed to the landing page, where they will be prompted to sign in again. If the user never signs off, they will remain logged in.
